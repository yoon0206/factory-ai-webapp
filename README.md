# Factory AI 웹앱

생산설비 소음의 FFT 주파수 분석과 점검 기록을 위한 초기 웹앱입니다.

## 실행
index.html을 Chrome 또는 Edge에서 열거나 정적 웹 호스팅에 배포합니다. 별도 서버나 API 키가 필요하지 않습니다.

## 기능
- 브라우저에서 지원하는 WAV/MP3/M4A 오디오 불러오기
- 8192점 FFT, Hann 창, 최대 240개 구간 평균
- 상대 주파수 스펙트럼 및 대역별 에너지 그래프
- 분석 CSV 및 설비 점검 기록 CSV 내보내기
- 브라우저 로컬 저장소에 점검 기록 보관

## 한계
실제 AI 모델을 학습하거나 결함을 자동 진단하는 기능은 아직 없습니다. 마이크 보정이 없어 절대 dB SPL 측정은 불가능합니다. 녹음 형식 지원은 브라우저와 운영체제에 따라 다릅니다. 진단에는 정상 기준 데이터, 회전수, 부하, 기계 사양 및 검증된 센서가 필요합니다.

## 보안
오디오 파일은 서버에 업로드되지 않습니다. 점검 기록은 브라우저에 저장되므로 CSV 백업이 필요합니다. 실제 생산 제어 장치와 연결하지 않습니다.
